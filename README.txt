KALIMA — telefon uchun web-ilova

1) ZIP faylni oching.
2) index.html faylini brauzerda ochib sinab ko‘rishingiz mumkin.
3) PWA sifatida bosh ekranga o‘rnatish uchun fayllarni HTTPS qo‘llaydigan statik hostingga joylashtirish kerak.
4) Sayt ochilgach Chrome menyusi (⋮) > Add to Home screen / Install app.
5) Lug‘at ma’lumotlari shu brauzerning localStorage xotirasida saqlanadi. Brauzer ma’lumotlarini tozalasangiz, ular o‘chishi mumkin. Zaxira nusxa tugmasidan foydalaning.
6) OCR Arabic Tesseract.js kutubxonasini CDN orqali yuklaydi; birinchi OCR uchun internet kerak. Matn aniqlanishi xato qilishi mumkin, natijani tekshiring. Hozircha OCR harakatlarni kafolatli aniqlamaydi.
7) O‘yinlar: tarjimani tanlash va juftliklarni topish. Boshqa o‘yinlar keyingi bosqichlarda qo‘shiladi.
